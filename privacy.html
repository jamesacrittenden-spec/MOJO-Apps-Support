Overview

This privacy policy applies to the MOJO rally apps and this support website. Individual MOJO apps may use device permissions and local data needed for their rally functions.

MOJO Monte Carlo Rally

MOJO Monte Carlo Rally uses device location information while the app is operating so it can calculate rally distance and related navigation information. Rally settings and checkpoint information are stored on the device for the app's operation.

The current MOJO Monte Carlo Rally app does not require a MOJO user account.

Information collected by this support website

This website is hosted using GitHub Pages. GitHub may process technical information associated with serving the site according to GitHub's own terms and privacy practices. MOJO does not use this site to request sensitive personal information.

Future MOJO apps

Other MOJO apps may have different functions, permissions, or data practices. This policy will be updated before those apps are distributed through this support site or an app store.

Changes to this policy

This policy may be updated as the MOJO apps change. The current version will always be posted on this page.
