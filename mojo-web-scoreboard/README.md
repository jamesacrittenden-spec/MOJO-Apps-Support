# Mojo Web Scoreboard

Firebase Hosting web scoreboard for Mojo rally events. Version 0.9.1 includes a note: a negative checkpoint score means the car arrived early; totals use penalty magnitudes.

The live web app is hosted at https://fir-tut-5e284.web.app . The source is maintained in this folder. Only the Firebase Hosting site is deployed; the web scoreboard does not edit rally scores.
