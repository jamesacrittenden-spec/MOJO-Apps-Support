What the app does

MOJO Monte Carlo Rally is designed to help a rally competitor follow a checkpoint schedule. The app maintains an odometer from GPS location updates, displays rally Keytime, and shows information for the next checkpoint including time, distance, and needed speed.

Starting a rally

  1. Open the app.
  2. Choose NEW RALLY to start a new event, or CONTINUE RALLY to resume an existing rally.
  3. On the Settings screen, enter the car number and review the odometer factor, distance units, minimum-speed filter, and voice setting.
  4. Continue to the checkpoint table and enter the checkpoint information supplied for the rally.

Checkpoint table

Each checkpoint entry contains a checkpoint number, mileage, and Key Time. Use the checkpoint table to add or edit the rally's checkpoint sequence. The app uses the next checkpoint in the table to calculate the main-screen guidance.

SPLIT

Press SPLIT on the main rally screen to freeze the displayed odometer while the underlying live odometer continues to process location updates. Press SPLIT again to return the display to the live odometer.

While SPLIT is active, the Settings screen provides small split-odometer adjustment buttons. Adjustments are applied to both the frozen split reading and the live odometer so that the rally can continue from the corrected value when SPLIT is released.

Odometer modes

The main screen provides REVERSE, PARK, and FORWARD odometer modes. Select the mode appropriate to the vehicle's movement.

GPS and location

The app requires location permission so it can receive GPS position updates and calculate rally distance. For best results, use the device where it has a clear view of the sky and verify the odometer before beginning a competitive section.

Important operating note

Rally competitors remain responsible for following the event's route instructions, official timing rules, posted road regulations, and safe driving practices. The app is an aid and should not replace the event's official instructions or the driver's judgment.

More help

If you encounter a problem, note the app version, what screen you were on, and what happened immediately before the problem. This information is especially useful when troubleshooting.
